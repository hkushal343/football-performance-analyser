# Final submission checklist

- [ ] App runs locally from a fresh virtual environment (`pip install -r requirements.txt`, `streamlit run app.py`).
- [ ] `python -m unittest discover -s tests -v` shows all tests passing.
- [ ] Manual test table in the README is ticked on your own machine.
- [ ] Every page opened at least once with no red error messages.
- [ ] Tried a phone-width browser window.
- [ ] Downloaded each CSV and opened it.
- [ ] Sidebar and README clearly say the data is synthetic sample data.
- [ ] Repository is on GitHub (public) and contains `app.py`, `requirements.txt`, `data/`, `src/`, `.streamlit/`, `tests/`.
- [ ] App deployed on Streamlit Community Cloud; public URL opens in a private browser window.
- [ ] URL and GitHub link written in your report or submission form.
- [ ] You can explain: data flow, two-rows-per-match idea, points rule, sort order, validation, caching.
- [ ] You have practised the demo in `docs/DEMO_AND_VIVA.md` and can answer the viva questions in your own words.
- [ ] A backup: screenshots of each page and the project ZIP on a USB drive or cloud storage.
